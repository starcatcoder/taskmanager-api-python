# 🚀 Task Manager API

Uma API REST robusta para gerenciamento de tarefas, desenvolvida com **FastAPI**. Este projeto foca em performance, documentação automática e boas práticas de desenvolvimento backend.

### 🛠️ Tecnologias:
- **Python**: Linguagem base.
- **FastAPI**: Framework web de alta performance.
- **Pydantic**: Validação de dados e esquemas.
- **Uvicorn**: Servidor ASGI rápido.

### ✨ Funcionalidades:
- CRUD completo de tarefas (Criar, Ler, Atualizar, Deletar).
- Documentação interativa automática via Swagger UI (`/docs`).
- Validação rigorosa de tipos de dados.
